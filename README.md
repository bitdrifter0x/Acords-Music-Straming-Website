# Acords-Music-Straming-Website 🎵 
A responsive, interactive **music player web application** built from scratch using **HTML, CSS, JavaScript**.  
This project demonstrates my ability to design, debug, and implement production‑grade front‑end features with clean UI/UX and robust event handling.

---

## ✨ Features

- **Album & Playlist Management**
  - Fetches album folders dynamically from a server directory.
  - Displays albums as interactive cards with cover images.
  - Clicking an album loads its songs into the player.

- **Song Playback**
  - Play, pause, previous, and next controls.
  - Auto‑advance to the next track.
  - Seek bar with real‑time progress updates.
  - Displays song title, artist, and duration.

- **Responsive Design**
  - Mobile‑friendly layout using CSS Grid and Flexbox.
  - Slide‑in animation for the right panel (playlist view).
  - Smooth transitions for an app‑like experience.

---

## Tech Stack

- **Frontend:** HTML, CSS (Flexbox, Grid, animations), JavaScript (DOM manipulation, event handling)
- **Data Handling:** Fetch API, DOMParser for parsing server directory listings
- **Other Tools:** Figma (UI design)

---

## How It Works

1. The app fetches available album folders from the `/albums/` directory.
2. Each album is displayed as a card with its cover image.
3. Clicking an album loads its songs dynamically into the playlist view.
4. The player supports full playback controls, seek bar, and duration display.

---

## Mobile Responsiveness

- The `.right` container (playlist view) slides in from the right when the **add icon** is clicked.
- Clicking an album card automatically closes the panel for a smooth UX.
- Layout adapts to different screen sizes using CSS Grid and Flexbox.
